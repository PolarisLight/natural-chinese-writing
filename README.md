# 自然中文写作

一个用于中文去AI味、自然表达和成稿语言审校的 AI 技能。按明确规则做最小修改，保留作者的事实、判断强度、体裁和文章框架。

技能名称：`natural-chinese-writing`。

## 关注的问题

- 冗余的自我辩护、免责声明、空泛谦辞和叠加对冲。
- 相邻句反复使用相同骨架，合句后动作之间缺少自然衔接。
- 主语、中心名词或主要动作出现过晚，长前置定语和前置从句集中堆积。
- 工具功能与使用状态的说明顺序，以及三项句内并列的连接方式。
- 揭晓式破折号、空转提示语、同义复述和聊天套话。

未命中规则的句子逐字保留。自然的“当……时”“对于……来说”和有作用的前后连接词继续保留，清楚的顿号清单保持原样。

## 安装与使用

在 Codex 中，可将本仓库放入个人技能目录：

```bash
git clone https://github.com/PolarisLight/natural-chinese-writing.git ~/.codex/skills/natural-chinese-writing
```

在支持技能调用的对话中使用：

```text
$natural-chinese-writing

请审校以下文字，保留事实、判断强度和文章框架，只输出审校后的全文：

〔待审校文字〕
```

需要查看修改依据时，可以要求输出“原文、改稿、对应规则”的对照表。

## 规则来源

规则整理参考了 `lieflat-less-ai-tone`、`anti-defensive-writing`、`humanizer`、`humanizer-cn` 和 `humanize-writing`，并结合逐条例句审阅，补充了中文语序、动作衔接和并列表达规则。

以明确的修改边界、信息守恒和必要限定为基础。完整规则与例外见 [references/rules-and-examples.md](references/rules-and-examples.md)。
